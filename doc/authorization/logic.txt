│  │ AccessControlService.validateAccess(context)                        │       │
│  │                                                                     │       │
│  │   1. if (!rbacEnabled) return Mono.just(true)                       │       │
│  │                                                                     │       │
│  │   2. getUser() → Extract từ SecurityContext                         │       │
│  │      ┌─────────────────────────────────────────┐                    │       │
│  │      │ RbacOAuth2User                          │                    │       │
│  │      │   .name() → "john"                      │                    │       │
│  │      │   .groups() → ["admin", "developer"]    │                    │       │
│  │      └─────────────────────────────────────────┘                    │       │
│  │                    │                                                │       │
│  │                    ▼                                                │       │
│  │      ┌─────────────────────────────────────────┐                    │       │

│  │      │   principal: "john"                     │                    │       │
│  │      │   groups: ["admin", "developer"]        │                    │       │
│  │      └─────────────────────────────────────────┘                    │       │
│  │                                                                     │       │
│  │   3. isClusterAccessible("production", user)                        │       │
│  │      - Filter roles where user.groups.contains(role.name)           │       │
│  │      - Check if any role has "production" in clusters               │       │
│  │      - Or defaultRole exists                                        │       │
│  │                                                                     │       │
│  │   4. getUserPermissions(user, "production")                         │       │
│  │      ┌─────────────────────────────────────────────────────────┐    │       │
│  │      │ Filter: roles where                                     │    │       │
│  │      │   user.groups.contains(role.name) = true                │    │       │
│  │      │   AND role.clusters.contains("production") = true       │    │       │
│  │      │                                                         │    │       │
│  │      │ Example matched role "admin":                           │    │       │
│  │      │   permissions: [                                        │    │       │
│  │      │     Permission {                                        │    │       │
│  │      │       resource: TOPIC                                   │    │       │
│  │      │       parsedActions: [VIEW, CREATE, EDIT, DELETE, ...]  │    │       │
│  │      │       compiledValuePattern: null (all topics)           │    │       │
│  │      │     }                                                   │    │       │
│  │      │   ]                                                     │    │       │
│  │      └─────────────────────────────────────────────────────────┘    │       │
│  │                                                                     │       │
│  │   5. context.isAccessible(userPermissions)                          │       │
│  │      - For each SingleResourceAccess in context:                    │       │
│  │        - Filter permissions by resourceType (TOPIC)                 │       │
│  │        - Match resource name "orders-topic" against patterns        │       │
│  │        - Collect allowedActions                                     │       │
│  │        - Check: allowedActions.containsAll([CREATE]) ?              │       │
│  │                                                                     │       │
│  │   6. Result:                                                        │       │
│  │      - true → Mono.empty() (continue)                               │       │
│  │      - false → Mono.error(AccessDeniedException)                    │       │
│  └─────────────────────────────────────────────────────────────────────┘       │
